📌 About

These projects were created during the early phase of my journey into AI/ML.
The focus was on understanding concepts by implementing them on real datasets using Jupyter notebooks.

Instead of just studying theory, I explored how models actually behave, how data is processed, and how predictions are made.

🧠 What’s Inside

The repository includes projects like:

Customer Churn Prediction using ANN
Breast Cancer Classification using Deep Learning
Electric Motor Analysis
Plant Disease Prediction

Each notebook walks through:

Data preprocessing
Model building
Training and evaluation
🛠️ Tech Stack
Python
NumPy, Pandas
Matplotlib / Seaborn
Scikit-learn
TensorFlow / Keras
Jupyter Notebook
📂 Structure
01_basics/ → Core learning projects and implementations
.ipynb files → Individual mini projects with full workflows
🎯 Purpose

This repo is mainly for:

Practicing ML/DL concepts
Understanding model behavior
